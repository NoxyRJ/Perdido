# 💌 Uma Pergunta Pra Você

Página web interativa criada para um pedido de namoro, feita em HTML, CSS e JavaScript puros — sem frameworks, sem build, um único arquivo.

## ✨ Funcionalidades

- Envelope animado que abre ao toque, dando início à experiência
- Sequência de perguntas com confirmação progressiva (indicador de progresso em corações)
- Botão "não" que foge do cursor/toque, sempre reposicionando dentro da tela
- Tela final personalizada com mensagem, efeitos de partículas e trilha sonora
- Efeitos de fundo (estrelas, pétalas, neve e corações caindo) em camadas sutis, atrás do conteúdo
- Totalmente responsivo — ajustado para funcionar bem em navegadores mobile (viewport travado, sem bugs de zoom/scroll)
- Bloqueio de seleção de texto e menu de contexto para preservar a surpresa

## 🛠️ Tecnologias

- HTML5
- CSS3 (animações, glassmorphism, variáveis CSS)
- JavaScript vanilla (sem bibliotecas externas)

## 🚀 Como usar

Basta abrir o arquivo `index.html` em qualquer navegador — não precisa de servidor nem instalação.

Ou basta clicar no link (https://noxyrj.github.io/Perdido/)
